# 手机业务总台需求与界面方案

记录日期：2026-10-28。
状态：已接入正式源码，发布前进行入口和完整业务回归；是否上线以发布 manifest 对应提交为准。

## 核心需求

同一份业务资料只填写一次。各入口使用同一套同步数据，后续业务关联原单并自动带出已有资料，不要求用户重复填写客户、供货商、货物、规格、数量、价格等相同信息。

系统自动带资料、计算、检查库存及关联单据；到货、完工、实发、实际收付款由用户确认。不能把数据同步等同于业务已经实际发生。

## 两条业务主线

### 备货流程

采购纸板 → 纸板入库 → 领纸板生产 → 成品入库。

- 选择供货商，带出常购规格及历史价格；采购入库带出原单，只核对实收数量，分批到货计算剩余。
- 备货不需要先有客户订单。
- 领料与完工属于同一生产业务；实际领用量和合格成品量需核对，不默认一张纸板等于一个纸箱。
- 手机操作可合并为“生产入库”：确认后扣纸板、增加成品并生成关联记录，同批成品不重复入库。
- 如有独立采购单，应与到货入库关联；是否已有采购单能力需核实，不把“采购纸板”显示成已实现的独立功能。

### 销售流程

客户下单 → 查看可用库存 → 客户出库 → 对账收款。

- 选择客户，带出常用货物、规格、历史价格及地址，只修改本次数量、交期或价格。
- 有可用库存直接确认发货；缺货计算缺口并关联安排生产，完工后继续原订单出库，不重复建立订单。
- 可用库存的计算口径、订单占用规则需要实施时明确，不能只按库存总数判断可发。
- 支持分批出库、部分收款，自动计算未发数量与剩余欠款。
- 送货单、对账单和打印内容使用保存的原单资料。

## 延伸需求

- 历史订单复制、常用客户/供货商/规格置顶、表单草稿保留。
- 按规格选择可用纸板批次；日常备货可复用历史生产资料。
- 盘点只填写实盘数量，自动计算差额并保留调整记录。
- 供货商付款带出未结账单；退货关联原出入库单并处理库存及账款。
- 单据扫码查询、关联记录追溯、缺料/交期/库存异常提醒。
- 历史已确认单据保留当时资料；客户地址或价格修改不覆盖旧单。
- 修改、取消、退货需明确关联影响，已发生的出库和结算不能直接覆盖。
- 防重复提交；联动失败不可造成库存、订单、账款部分成功且无可见处理状态。

## 手机界面建议

保留蓝白风格及现有底部导航，以任务办理为主。

1. 紧凑页头：品牌、业务总台、刷新；日期与同步状态一行，不显示秒钟。
2. 异常待办：有异常显示最急事项及处理入口；无待办收为一行。
3. “办业务”区域：切换“销售 / 备货”，每个区域显示可点击的流程步骤及主要操作。
4. 销售区域：突出“客户开单”，展示待发订单；订单按状态显示“确认出库 / 安排生产 / 登记收款”等下一步操作。
5. 备货区域：突出“纸板入库”和“生产入库”；采购功能已有时提供采购单入口，否则先保留流程说明。
6. 经营摘要：待发货、库存预警、待收款、待付款，点击进入相应筛选结果。
7. 管理入口：客户、供货商、收付款、更多；库存使用现有底部入口。
8. 最近动态：少量记录直接查看关联原单，无记录时显示紧凑空状态。

流程需使用可换行的步骤或两行布局，避免手机上横排四步导致小字、截断或难以点击。流程状态应基于选中的订单/单据；没有选择单据时只作导航，不能显示虚假的全局完成进度。

## 实施顺序和验收

第一阶段：手机首页布局、两条流程导航、入口名称与空状态整理。
第二阶段：客户开单资料复用、库存判断、关联生产/出库/收款及原单打印。
第三阶段：采购关联、分批办理、退货、草稿及扫码追溯等扩展。

验收：相同资料不重复填写；下一步自动带原单；库存与账款影响可追溯；不重复记账；失败可恢复；手机安全区与底部导航不遮挡内容；多设备同步后显示一致。

发布时遵守仓库 AGENTS.md：完成验证并集成 main 后，通过 .github/workflows/publish-hotupdate.yml 发布，核实发布 manifest 对应提交及实际行为。

## 本次实际接入

- 首页切换销售、备货业务，显示真实待处理订单、库存预警、往来余额。
- 库存统一使用网页总台；旧纸板库存地址仍可打开，内容进入新版库存。
- 客户、供货商、收付款共用正式接口；旧账本地址保留筛选条件转到新版账单。
- 纸板入库可从客户共享规格带入成箱尺寸；实际纸板尺寸选填。已知纸板尺寸时按面积和张数计算平米；不能从成箱尺寸擅自推算纸板实际展开尺寸。
- 纸板金额支持按平米、手工总额、待补三种状态，待补不显示为已确认零元。已有领料后，仅允许补录待补金额，不能借此重写库存数量或来源。
- 纸箱入库保存入库金额和关联客户，不新增加客户应收；实际出库产生应收。旧入库已计客户应收的数据保持历史抵扣，避免发货时重复计费。
- 库存显示客户、供货商、业务日期和系统登记时间；聚合成品库存存在多来源时明确展示全部关联单位，不把最新一笔误认为全部库存的归属。
- 打印保留送货单原模板，支持选择已保存出库自动开单、手工填写送货单、历史单据重印、标签及对账单预览。
- 对账单来自所选往来单位的真实账本流水。当前余额与期间发生额分别标明；浏览器打印使用独立打印层，避免应用容器将打印内容遮蔽。
- 订单、商品、记录、客户编辑、团队、备份、计算器和扫码详情保留实际功能，并统一网页页头及返回路径。
