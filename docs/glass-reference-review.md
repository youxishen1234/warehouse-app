## 从视频取样

- 5.5 秒附近的白色背景便于测量静止形态：未选中图标约 `#121212`，选中图标内部主要像素约 `#ae0d20`。视频压缩会导致相邻像素颜色不同。
- 按 440 点宽的画面换算，底栏约 64 点高，左右约 20 点，搜索按钮独立放在右侧。
- 3～4.5 秒附近展示选中胶囊连续移动。拖动时胶囊扩大，图标被放大、折射，边缘出现色散；松手后落到选中项。

## 实现

- iOS 26：使用系统 `UITabBarController`、`UITab` 和 `UISearchTab`，保留系统玻璃材质及其手势。一个 Capacitor bridge 在四个宿主控制器之间移动，避免重建业务页面。
- 网页及旧版 iOS：使用同一套四项导航、单独搜索按钮、连续指针位置、松手吸附、取消恢复，以及背景位移与图标色散滤镜。浏览器的背景滤镜能力不同，不能视为与 iOS 系统玻璃逐像素等价。
- 搜索入口接到商品搜索，搜索返回时恢复之前被 Taro 遮蔽的 Tab 页面。
- `scripts/preview-glass.cjs` 提供本地视频与当前网页构建的对照页，接口使用演示响应，不提交业务数据。参考视频转码保存在忽略提交的 `release/glass-reference-browser.mp4`。

## 本地验证

运行 `npm run build:h5`、`node tests/navigation-browser.cjs`。

浏览器回归覆盖 Chromium、WebKit：胶囊中间位置、松手切换、跨多项拖动、取消、键盘、Chromium 真触摸事件、正文滑动、搜索及返回、原生握手、旧版回退、弹窗、横屏和页面底部可达性。截图输出到 `release/glass-*.png`。

导航模块单独类型检查：

```powershell
npx tsc --noEmit --target es2020 --moduleResolution node --skipLibCheck src/services/glass-tabbar.ts src/services/tab-navigation.ts
```

全项目 `tsc --noEmit` 仍有已有的 SCSS 类型声明缺失、Taro 属性类型、未使用变量等错误，不能把 H5 构建成功当作全项目类型检查通过。
