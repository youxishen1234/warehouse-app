# 账单流水的凭证照片

实现及上线日期：2026-10-04。入口：业务总台 → 查看账单流水 → 点击一笔流水 → 单据凭证；我的工作台原有“账单流水”入口也可使用。

支持送货单、签收单、收款凭证三种分类。可选择多张照片或拍照，先在待上传区域确认，再上传到当前流水。每笔最多 20 张，单张最多 12 MiB，支持 JPEG、PNG、WebP。HEIC 需要先另存为 JPG；客户端不会静默压缩或旋转已选择的原图。

保存成功后显示缩略图和数量，可以放大、滚动查看、保存原图。显示状态为“已上传 · 待核对”；上传不代表已签字、已核对或已收到钱，也不会修改库存、应收或收支金额。照片保留在其原流水 ID 下，同时保存客户／供应商、业务流水、单号、金额及记账日期快照。

上传失败时，照片保留在当前页面，关闭详情再打开同一笔流水仍可重试；切换到另一笔流水不会把草稿带过去。未知上传结果重用提交编号，服务端同时按流水、分类与内容校验值防止重复挂图。待上传内容只在页面内存中，刷新页面或强制退出 App 后的草稿恢复尚未实现，界面有明确提示。已上传照片保存在服务器，重新打开可读取。

## 服务端保存与备份

- 新接口：`GET/POST /api/ledger/:id/attachments`；原图接口：`GET /api/ledger/:id/attachments/:attachmentId/content`。原图按需返回，普通流水列表只包含附件元数据。
- 文件位于 `${WAREHOUSE_DATA_FILE}.attachments/`，默认 `backend/data.json.attachments/`，不在公共静态资源目录。原图保持上传字节，使用 SHA-256 校验并以临时文件写入、同步后重命名。附件元数据与提交回执随数据库事务保存；失败事务产生的无引用文件不对外可见，目前不自动清理凭证文件。
- 图片接口及包含照片的备份导出要求有效的现有会话。线上保留现有管理员、操作员、只读账号及共享访客；只读账号可查看、不能上传，恢复须管理员或现有共享管理权限。不新增账号或角色，也不按个人或客户隔离图片。
- 手动完整备份和自动备份都包含原图、索引、关联快照与校验值。导入会校验完整文件集，缺图或校验错误时拒绝恢复，不覆盖当前账务。
- `backupData()` 内部快照只返回元数据；对外导出必须使用 `backupData({ includeAttachments: true })`。正式 HTTP 导出同时检查 `WAREHOUSE_BACKUP_MAX_MB` 的限制（默认 64 MiB，可配置 5–256 MiB）；超限时明确报错，不导出缺照片的半份备份。恢复请求的重试内容只保存在内存，不把包含原图的 JSON 写入浏览器本地存储。
- 原图不提供删除或覆盖入口；作废流水保留附件与文件。
