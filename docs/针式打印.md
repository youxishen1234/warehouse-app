# 针式打印

入口：首页「针式打印」、我的「打印中心」，或出库单预览中的「针式打印 / 保存 PDF」。

## 使用

1. 在连接打印机的电脑浏览器或 Windows 客户端打开打印中心。
2. 选择单据。同一出库单号的明细会重新完整读取，即使明细跨越流水列表的分页；入库按单条流水生成入库凭证。作废、已删除或读取失败的单据不能打印。
3. 按纸张实测尺寸选择 241 × 140、241 × 93、241 × 279 mm、A4，或自定义纸张。当前确认的三层彩纸默认使用 241 × 93 mm（三等分），预览按真实尺寸排版，屏幕显示时缩放。
4. 首次先打印测试样张。在系统打印窗口选针式打印机，并在驱动中选相同纸张尺寸；缩放 100%，边距选无，关闭页眉页脚。多联复写纸使用一份打印任务，联数由纸张决定。
5. 如位置有偏差，在「排版与位置校准」中调整左右、上下偏移。正数向右／下，负数向左／上。设置仅保存在本机。

本机预览页 `http://127.0.0.1:4316/index.html#/pages/print-center/index` 现在提供「本机打印机」卡片，可直接选择 Windows 已安装的设备，选择会保存在本机。点击打印会按所选设备的系统名称发送一份任务，不再依赖嵌入浏览器中打不开的目标打印机下拉框。失联、离线或已移除的设备会阻止发送，不会自动改用其他设备。连接结果不确定时，重复点击会查询同一任务，避免重发。当前 Deli A4 Printer 被 Windows 标记为离线；EPSON LQ-630KII ESC/P2 为默认可用设备。

本机通道按页面所选尺寸、100% 比例、无边距、无页眉页脚生成打印任务。Microsoft Print to PDF 卡片生成 PDF 文件；普通浏览器可下载，具体保存行为由宿主浏览器决定。这个通道由本地预览服务提供，尚未部署到线上网页或打包到 Windows 客户端；其他入口继续使用原系统打印窗口。

可修改公司抬头、字号、每页最多明细行数，以及是否显示价格。内容区最多 180 mm 宽并预留进纸孔边和右侧安全区；实际可打印区域仍需按设备和纸张试打确认。长明细会根据实际字体和行高自动分页，每页重复单号、表头、页码、签收栏，并区分本页小计与整单合计。单行过长、无法完整放入纸张时会阻止打印并提示调整。

当前模板适用于空白连续纸。已有印刷表格的单据需要依据原纸设计套打模板。手机 App 提供预览；没有接入原生打印桥接，需从电脑打印。系统打印窗口也可选择保存 PDF。

「流水报表」继续支持打印已加载的全部流水。它与针式单据使用不同入口。

## 实现与验证

- `src/utils/dot-matrix-print.ts`：单据快照、纸张配置、独立 HTML、按实际 DOM 尺寸分页。
- `src/components/DotMatrixPrint/`：设置、校准、预览与系统打印调用。
- `src/utils/local-print.ts`、`scripts/dot-matrix-native.cjs`、`scripts/dot-matrix-electron.cjs`：本机设备选择、验证后的结构化打印资料、隔离的本地渲染及明确指定设备。
- `src/pages/print-center/`：单据选择、完整读取、失败重试与原流水报表。

预览与打印不修改库存、订单、账务，也不将业务明细保存到本地。打印窗口关闭或取消不会标记为“打印成功”。HTML 中的业务文本均转义，预览 iframe 不允许执行脚本。

验证命令（PowerShell）：

```powershell
npm run typecheck
node --test tests/dot-matrix-print.test.cjs tests/print-center-row-memo.test.cjs
node --test tests/dot-matrix-native.test.cjs
$env:TARO_OUTPUT_DIR = 'release/dot-matrix-web'
npm run build:h5
node tests/dot-matrix-browser.cjs
node tests/dot-matrix-native-render.cjs
```

浏览器测试使用独立模拟数据，不访问实际仓库。覆盖 Chromium / WebKit、跨分页单据、纸张尺寸、PDF 页数、长明细、隐藏金额、校准保存、失败重试、作废检查、切换单据时的请求竞态、手机预览，以及原流水报表。截图及测试 PDF 写入 `release/dot-matrix-check/`。

软件验证不代替针式打印机的实际出纸校准。本次未执行真机打印。

### 文字发虚、小字断笔

默认启用「清晰无衬线字体」：正文使用 Noto Sans SC，缺失时回退微软雅黑，默认 11 pt，标题适度加粗。纸张、抬头、价格显示和校准值会保留；旧版宋体 10 pt 设置迁移到新正文 11 pt。短纸张采用紧凑间距，仍按真实字体尺寸分页，过长单行继续阻止打印，不缩小或裁切文字。浏览器备用打印区域继承与预览完全相同的字体和字重。「放大查看文字」按 100% 至 150% 显示屏幕预览，不改变打印尺寸。

包装照片已确认本次实际纸张为三层彩、三等分，页面使用 241 × 93 mm。当前选用 EPSON LQ-630K ESC/P2；其原默认纸张为 A4，已有「三等分」纸型宽度仅 210 mm。已用 `scripts/set-dot-matrix-paper.ps1 -WidthMm 241 -HeightMm 93 -Apply` 校正当前用户默认纸张，回读为 241.046 × 92.964 mm。该驱动回报可打印宽度为 203.2 mm，原居中 200 mm 表格的右边超过此范围；模板改为 180 mm 内容区，保持字体大小，通过换行与分页保护右侧日期、备注、金额。此次仅做 PDF 和预览校验，没有自动发送实体打印。

本机 EPSON 原用户设置为 180 × 180 dpi。已依据驱动实际支持的选项将当前用户偏好改为 360 × 180 dpi、单向、TrueType 以图形位图方式打印，避免驱动替换成过小的内置点阵中文字体，并验证纸张仍为 241.3 × 139.7 mm、纵向。修改脚本 `scripts/set-dot-matrix-quality.ps1` 默认只读，`-Apply` 才保存；仅改当前用户质量偏好，先备份完整 DEVMODE，回读不匹配会恢复。此次修改备份为 `release/dot-matrix-check/epson-quality-20261004-085758.devmode`。

清晰模式的本机任务读取 EPSON 支持的分辨率后明确发送 360 × 180 dpi，其他型号保留其驱动分辨率，不猜测 600/1200 dpi。仅软件、驱动回读和 PDF 校验通过，纸面清晰度需要用新样张确认。本次未额外发送实体打印任务。

本机打印服务仅监听 127.0.0.1，校验 Host、Origin 和每次启动生成的随机访问令牌，限制单据大小，拒绝任意 HTML、网址和打印选项。渲染页面禁用脚本、网络、Node 和系统权限，仅加载本地可信模板；临时资料在任务结束后清理。任务编号在一次服务运行期间去重，超时提示先核对打印队列；不自动重试实体打印。原有浏览器打印隔离、连续纸排版和流水报表保持可用。

本次验证覆盖真实设备列表读取、Chromium / WebKit 卡片切换与选择保存、明确传递设备名称、离线和移除设备、重复点击及连接失败。原生渲染校验只导出 PDF：12 条明细、241.3 × 139.7 mm、3 页，同时验证失效及离线设备被拒绝；未调用实体打印 API。

## 偏移、裁切或出现网址

- 正式打印使用页面根部的独立打印区域，复制已分页的单据，并隔离应用样式；不直接打印带有缩放和滚动容器的预览 iframe。打印完成、取消或离开页面后清理打印区域，普通页面和流水报表恢复原状。
- 连续纸尺寸必须同时匹配页面和驱动。三层彩三等分纸使用 241 × 93 mm；页面不会把打印机驱动的 A4 自动改成连续纸。先在打印窗口的打印机属性中核对纸型。
- 已检查的 EPSON LQ-630KII ESC/P2 驱动提供「复写 9.5 x 5.5 英寸」，实际为 241.3 × 139.7 mm；使用该纸型时，可将页面设为同样的自定义尺寸。三等分对应「复写 9.5 x 3 2/3 英寸」。最终以实际纸张测量值为准，核对预览宽高方向与驱动一致，避免再旋转一次。
- 浏览器日期、网址属于页眉页脚，需要在打印窗口中关闭。比例用 100%，边距选无；确认版式没有裁切后再用单张样纸校准走纸位置。
- 浏览器回归测试直接调用真实打印入口，在完整应用页面上检查打印原点、所有表格列的边界、窄屏缩放隔离、纸张尺寸和分页，并验证取消后恢复；不再只把 iframe 内容导出到空白页面验证。
