# 曙光送货单桌面打印工具

运行 `npm run print:desktop`，或使用桌面的“曙光送货单打印”快捷方式。

依赖当前项目的 node_modules 和 Electron 运行时，快捷方式不是独立安装包。移动仓库后需要重新设置快捷方式路径。

使用 `src/utils/dot-matrix-print.ts` 中的 `delivery-note` 原模板和分页规则，不维护另一套单据排版。固定纸张为 241 × 93 mm，8 列，短单补足 5 行；长单自动分页。

1. 填写客户、日期和货物。
2. 需要核对排版时，点击“更新预览”。
3. 选择本机实体打印机，点击“发送打印”，立即静默发送一份，不再弹出第二次确认。所选打印机会记住，下次打开继续使用。
4. 需要 PDF 时选择“导出 PDF”。

打印结果为系统接受排队，不代表已经出纸。遇到失败或等待时先核对打印队列及实际出纸，再决定是否重发。此工具只打印，不登记库存、出库或客户应收，也不接远程打印任务。

本机目标打印机：EPSON LQ-630K ESC/P2。测试使用隔离单据和模拟打印回调，不自动打印测试纸张；实际走纸仍以打印机现场结果为准。
